## 一、客户端类型维度

### 1.1 H5 端（移动端网页）

#### 后端知识

| 类别 | 技术/知识 | 说明 |
|---|---|---|
| **API 设计** | RESTful API | 标准 HTTP 接口 |
| **数据格式** | JSON | 主流数据交换格式 |
| **分页** | 游标分页（cursor） | 移动端一次加载不能太多，游标比偏移分页更高效 |
| **图片处理** | 图片 URL + 缩略图 | 返回图片 URL，前端直接显示 |
| **流式响应** | SSE（Server-Sent Events） | AI 对话等需要流式输出的场景 |
| **CORS 配置** | 跨域处理 | H5 页面在不同域名下需要 CORS |
| **接口精简** | 返回必要字段 | 移动端流量敏感，不要返回多余字段 |

#### 前端知识

| 类别 | 技术/知识 | 说明 |
|---|---|---|
| **框架** | Vue / React / 原生 | 主流选择 |
| **移动端适配** | 响应式布局 / rem / vw | 适配不同屏幕尺寸 |
| **网络请求** | axios / fetch | HTTP 请求库 |
| **SSE 处理** | EventSource / fetch + ReadableStream | 接收流式响应 |
| **状态管理** | Pinia / Vuex / Redux | 前端状态管理 |
| **路由** | Vue Router / React Router | 前端路由 |
| **弱网优化** | 请求超时、重试、缓存 | 移动端网络不稳定 |
| **性能优化** | 懒加载、预加载、骨架屏 | 提升首屏体验 |

## 学习路径建议

### 后端学习顺序

```
1. 编程语言（TypeScript/Node.js）
   ↓
2. Web 框架（NestJS）
   ↓
3. 数据库（MySQL + Prisma）
   ↓
4. Redis（缓存/会话/限流）
   ↓
5. API 设计（RESTful + SSE）
   ↓
6. 认证与安全（JWT + RBAC）
   ↓
7. Docker 部署
   ↓
8. 深入：事务、索引优化、分布式锁
   ↓
9. 深入：WebSocket、推送通知
   ↓
10. 深入：CI/CD、监控告警
```

### 前端学习顺序

```
1. HTML + CSS + JavaScript 基础
   ↓
2. 框架（Vue / React）
   ↓
3. 状态管理（Pinia / Redux）
   ↓
4. 路由（Vue Router / React Router）
   ↓
5. HTTP 请求（axios）
   ↓
6. 移动端适配（响应式布局）
   ↓
7. 小程序开发（原生 / uni-app）
   ↓
8. 移动端开发（React Native / Flutter）
   ↓
9. 性能优化（懒加载、骨架屏）
```

## 你的项目覆盖度

| 维度 | 覆盖情况 |
|---|---|
| **客户端类型** | ✅ H5 + Web（Vue 前端） |
| **项目类型** | ✅ 聊天/AI 对话类 |
| **后端通用知识** | ✅ 80%（缺 CI/CD、监控） |
| **聊天类额外知识** | ✅ 全部覆盖 |
| **前端知识** | ✅ Vue + 响应式 + SSE 接收 |

**一句话**：你的项目是一个很好的后端学习项目，覆盖了大部分核心知识。理解架构后，其他项目类型只是在这个基础上加特定领域知识。
