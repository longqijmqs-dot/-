## 一、日常维护

### 1. 查看服务状态

```bash
# 连接服务器
ssh -i C:\Users\33281\.ssh\aliyun_key.pem root@47.97.241.42

# 查看所有容器状态
docker compose -f /root/ai-chat-platform/compose.yaml ps

# 正常输出应该是 4 个容器都是 healthy
```

### 2. 查看日志

```bash
# 查看所有服务日志（实时）
docker compose -f /root/ai-chat-platform/compose.yaml logs -f

# 只看后端 API 日志
docker compose -f /root/ai-chat-platform/compose.yaml logs -f api

# 只看前端 Web 日志
docker compose -f /root/ai-chat-platform/compose.yaml logs -f web

# 查看最近 100 行日志
docker compose -f /root/ai-chat-platform/compose.yaml logs --tail=100 api
```

### 3. 重启服务

```bash
# 重启全部服务
docker compose -f /root/ai-chat-platform/compose.yaml restart

# 只重启后端（不影响前端和数据库）
docker compose -f /root/ai-chat-platform/compose.yaml restart api

# 只重启前端
docker compose -f /root/ai-chat-platform/compose.yaml restart web

# 完全停止再启动（会短暂中断）
docker compose -f /root/ai-chat-platform/compose.yaml down
docker compose -f /root/ai-chat-platform/compose.yaml up -d
```

### 4. 查看资源占用

```bash
# 查看容器资源占用
docker stats

# 查看磁盘空间
df -h

# 查看 Docker 镜像占用
docker images
```

## 二、代码更新部署（核心流程）

### 完整流程：本地改代码 → 上传 → 重新构建 → 验证

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐     ┌─────────────┐
│  本地改代码  │ ──→ │  打包上传到服务器 │ ──→ │  重新构建镜像  │ ──→ │  验证访问正常  │
└─────────────┘     └──────────────┘     └──────────────┘     └─────────────┘
```

### 步骤 1：本地打包代码

在 Windows 上执行（PowerShell）：

```powershell
# 进入项目目录
cd "C:\Users\33281\Desktop\测试"

# 打包（排除不需要的文件，减小体积）
tar --exclude='node_modules' --exclude='.git' --exclude='.DS_Store' ^
    --exclude='dist' --exclude='.pnpm-store' --exclude='.tmp' ^
    --exclude='uploads' ^
    -czf C:\Users\33281\project-update.tar.gz .
```

### 步骤 2：上传到服务器

```powershell
# 上传压缩包
scp -i C:\Users\33281\.ssh\aliyun_key.pem ^
    C:\Users\33281\project-update.tar.gz ^
    root@47.97.241.42:/root/project-update.tar.gz
```

### 步骤 3：服务器上重新部署

```bash
# SSH 登录服务器
ssh -i C:\Users\33281\.ssh\aliyun_key.pem root@47.97.241.42

# 备份旧代码（重要！出问题可以回滚）
cd /root
cp -r ai-chat-platform ai-chat-platform-backup-$(date +%Y%m%d-%H%M%S)

# 解压新代码
rm -rf ai-chat-platform
mkdir ai-chat-platform
tar -xzf project-update.tar.gz -C ai-chat-platform

# 恢复 .env 文件（新代码包里可能没有）
cp ai-chat-platform-backup-*/.env ai-chat-platform/.env 2>/dev/null

# 重新构建并启动
cd ai-chat-platform
docker compose -f compose.yaml up -d --build
```

### 步骤 4：验证

```bash
# 检查容器状态
docker compose -f compose.yaml ps

# 检查日志有没有报错
docker compose -f compose.yaml logs --tail=20 api
docker compose -f compose.yaml logs --tail=20 web

# 测试访问
curl -s -o /dev/null -w "%{http_code}" http://localhost:80
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/docs
```

### 步骤 5：如果有数据库变更

```bash
# 同步 Prisma schema 到数据库
docker compose -f compose.yaml exec api sh -c "cd apps/api && npx prisma db push"
```

## 五、数据库维护

### 备份数据库

```bash
# 备份整个数据库
docker compose -f /root/ai-chat-platform/compose.yaml exec mysql \
  mysqldump -u root -p'你的MYSQL_ROOT_PASSWORD' ai_chat > /root/db-backup-$(date +%Y%m%d).sql

# 下载到本地
scp -i C:\Users\33281\.ssh\aliyun_key.pem \
  root@47.97.241.42:/root/db-backup-*.sql \
  C:\Users\33281\Desktop\
```

### 恢复数据库

```bash
# 从备份恢复
docker compose -f /root/ai-chat-platform/compose.yaml exec -T mysql \
  mysql -u root -p'你的MYSQL_ROOT_PASSWORD' ai_chat < /root/db-backup-20250101.sql
```

### 直接操作数据库

```bash
# 进入 MySQL 命令行
docker compose -f /root/ai-chat-platform/compose.yaml exec mysql \
  mysql -u root -p'你的MYSQL_ROOT_PASSWORD' ai_chat

# 常用 SQL
SHOW TABLES;                    -- 查看所有表
SELECT * FROM users LIMIT 10;   -- 查看用户
SELECT * FROM roles;            -- 查看角色
```

## 八、常见问题排查

### 问题 1：网站打不开

```bash
# 1. 检查容器是否在运行
docker compose -f /root/ai-chat-platform/compose.yaml ps

# 2. 检查端口是否监听
ss -tlnp | grep -E '80|3000'

# 3. 检查防火墙
ufw status

# 4. 检查阿里云安全组（在控制台查看）
```

### 问题 2：API 报错 500

```bash
# 查看后端日志
docker compose -f /root/ai-chat-platform/compose.yaml logs --tail=50 api
```

### 问题 3：数据库连接失败

```bash
# 检查 MySQL 容器状态
docker compose -f /root/ai-chat-platform/compose.yaml ps mysql

# 检查 MySQL 日志
docker compose -f /root/ai-chat-platform/compose.yaml logs mysql

# 测试数据库连接
docker compose -f /root/ai-chat-platform/compose.yaml exec mysql \
  mysql -u root -p'你的MYSQL_ROOT_PASSWORD' -e "SELECT 1"
```

### 问题 4：磁盘满了

```bash
# 查看磁盘使用
df -h

# 查看 Docker 占用
docker system df

# 清理空间
docker system prune -a -f
```
